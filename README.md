# MSTrabalho
Repositório dedicado para o trabalho extra de mecânica dos sólidos sobre cálculo de Flambagem. Contendo um código fonte em C para ser compilado.

## Compilar o projeto
A linha de comando a seguir gerará um arquivo executável .exe.
```bash
gcc MSTrabalho.c -o MSTrabalho
```

## Trabalho
Contém o arquivo do código fonte da aplicação.
